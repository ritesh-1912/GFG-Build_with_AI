# GitHub Dev Card Generator

Expert Python-based project building a GitHub Dev Card Generator.

## Tech Stack
- Orchestration: Google ADK
- Tools: MCP (FastMCP)
- LLM: Gemini 2.5 Flash
- Backend: FastAPI
- Frontend: React/HTML
- Deployment: Google Cloud Run
- Dependency Management: uv

## Standards
- Clean, modular Python.
- Surgical updates using replace tool.
- Rigorous validation and testing.
